# WhatNow

WhatNow is a university project about helping people handle stressful life-admin situations. When something goes wrong, it can be difficult to work out what to do first, what information matters, and which instructions can be trusted.

The proposed solution is an AI-assisted platform that turns a user's description of a real-life problem into a clear, prioritized action plan. AI will help understand the situation and explain the plan, while verified structured sources will provide authoritative procedures, deadlines, contact details, and safety information.

## Initial MVP

The first minimum viable product will focus on a lost or stolen phone workflow. It will explore how the platform can collect key facts, identify missing information, and organize appropriate next steps for this single scenario.

## AI Usage

AI is intended for tasks that benefit from natural-language understanding, including classifying a situation, extracting facts from a user's description, interpreting updates, and explaining actions clearly.

Deterministic application logic will manage plan state, priorities, completed steps, and validation rules. Official procedures, legal requirements, contact details, deadlines, and authoritative safety information will come from verified structured sources rather than from the AI.

## Project Status

The project is currently in initial setup and architecture design. No application functionality or AI integration has been implemented yet.
